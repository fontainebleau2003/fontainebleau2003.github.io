Locking Trend

frequency ratio · phase error · Vc
1 PFD · compare arrivals

Two edge sensors compare each reference tick with the divided feedback tick. Early/late timing becomes UP or DN pulses.

2 Charge pump · move charge

UP pushes current into the filter; DN pulls it back. The current control changes the correction rate.

3 Loop filter · smooth error

The RC channel integrates pulse packets into a steady control voltage, suppressing ripple and setting loop response.

4 VCO + divider · close loop

Vc tunes the flywheel oscillator. The divider returns fVCO/N; lock occurs when feedback edges track REF.
