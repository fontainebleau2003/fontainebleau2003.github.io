LIVE PHASE

One shared model

The phase, counters, routes, indexers and readout all use the same clocked preview model. Opening the cover only changes the inspection pose.

The small grid and raised pool samples are deterministic examples. cdata_wr, pooled maxima and the 40-bit accumulator stay unknown because the required external memory values are absent.

Model scale: 16×16 image → 8×8 pooled plane per channel → 128 interleaved output words. CONV.v uses 64×64 → 32×32 per channel → 2,048 output words. A READY sampling edge starts either run; DONE holds until RESET.
